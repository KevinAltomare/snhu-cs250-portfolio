# snhu-cs250-portfolio
# Final project for CS250 – Software Development Lifecycle
This repository contains my Sprint Review and Retrospective deliverable for the final project in CS250. The project brings together the Agile and Scrum practices used throughout the course, including user stories, sprint planning, communication, and reflection on team roles.

# Essential Questions
## How do I interpret user needs and implement them into a program? How does creating user stories help with this?  
I interpret user needs by focusing on what the user is trying to accomplish and why it matters. User stories help because they describe features from the user’s point of view, which keeps the team centered on real goals instead of assumptions. Clear acceptance criteria and ongoing communication make it easier to turn those needs into working software.

## How do I approach developing programs? What Agile processes do I hope to incorporate into my future development work?  
I approach development as an iterative process where change is expected. I try to plan everything out thoroughly from the beginning, but this isn't always reality. Agile practices like user stories, backlog refinement, daily standups, and retrospectives help keep work organized and flexible. These processes make it easier to adjust when requirements shift as they inevitably do, surface blockers early, and deliver small increments of value. I plan to keep using these practices because they are applicable to so many different environments.

## What does it mean to be a good team member in software development?  
Being a good team member means practicing open communication, asking questions when something is unclear, and supporting others when priorities change. It also means being reliable, sharing updates honestly, and helping the team stay aligned. You can bring value to a team in many different ways. In a world where AI is quickly replacing junior developers and doing lots of the grunt work, bringing value to a team is more than just producing code. Good teamwork makes it easier for everyone to succeed and produce genuinely useful things for the world.
